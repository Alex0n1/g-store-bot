G STORE — ПОЛНЫЙ КОМПЛЕКТ TELEGRAM-БОТА

ЧТО ВНУТРИ
- bot.py — весь код бота и админ-панели
- requirements.txt — зависимости
- .env.example — пример настроек
- START_BOT.bat — автоматический запуск Windows
- START_BOT.sh — автоматический запуск Linux/macOS
- shop.db создаётся автоматически при первом запуске

КАК ЗАПУСТИТЬ НА WINDOWS
1. Распакуйте архив в одну папку.
2. Установите Python 3.11+ с https://www.python.org/downloads/ (при установке отметьте Add Python to PATH).
3. Дважды нажмите «START_BOT.bat».
4. При первом запуске вставьте НОВЫЙ токен, полученный у @BotFather.
5. Оставьте окно терминала открытым — пока оно работает, бот онлайн.

КАК ЗАПУСТИТЬ НА LINUX/macOS
Откройте терминал в папке проекта и выполните: bash START_BOT.sh

АДМИНИСТРАТОР
Единственный администратор: Telegram ID 8328202124.
Админ-панель доступна этому аккаунту в меню бота. В ней можно управлять остатками,
добавлять аккаунты по регионам, менять цены, контакт оплаты, приветствие и заказы.

ВАЖНО
- В архив намеренно не включён ваш старый .env и токен бота.
- Если старый токен уже отправлялся кому-либо или попадал в переписку,
  отзовите его через @BotFather (/revoke) и используйте новый.
- Не удаляйте shop.db после запуска: в ней хранятся товары, настройки и заказы.
- Для постоянной работы 24/7 нужен включённый компьютер или сервер.
- Используйте только аккаунты, которые вы вправе продавать или передавать.
